# Derived reference bundle parts

These files are consecutive binary parts of `AdaptiveLearningSim_KT1_reference_bundle.zip`.
They are split only to keep every repository file below the GitHub browser-upload limit.

Reassemble and verify the bundle from the repository root with:

```bash
python raw_pipeline/reference_bundle_parts/assemble_reference_bundle.py
```

Do not edit the `.part*` files. The expected SHA-256 digest of the reconstructed archive is stored in `REFERENCE_BUNDLE_SHA256.txt`.
