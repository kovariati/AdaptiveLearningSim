# Reproducibility statement

The resource separates four distinct claims.

1. **Executable consistency.** Regression tests and runtime checks verify exercised mathematical invariants, absolute-time synchronization, shared response mapping, challenge-learning normalization, and deterministic data transformations.
2. **Precursor empirical prediction.** Held-out EdNet metrics refer to the precursor skill-level BKT and BKT-F calibration models.
3. **Final binary benchmark construction.** Empirical-Bayes shrinkage and marginal-accuracy-anchored item shifts are applied after precursor fitting. The complete binary simulator therefore does not have a fully untouched end-to-end learner holdout.
4. **Designed structural stress.** The continuous and four-state worlds are moment-matched constructions used to test assumption dependence rather than independently validated alternatives.

The main cross-world endpoint is the delayed expected response score, which removes avoidable Bernoulli evaluation noise while preserving the shared response mapping. Simulation-replication intervals quantify finite Monte Carlo variation only.

The raw EdNet learner logs are not included. Full raw replay requires the public EdNet files. The compact benchmark can be reproduced from the included derived calibration artifacts.
